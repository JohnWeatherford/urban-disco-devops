# Objective
## Goal: How a full-stack data round-trip:
* Client (front-end) -> Server (Express.js) -> Database (MongoDB) -> Server -> Client
* Demonstrate full CRUD functionality:
* Create → POST
* Read → GET
* Update → PUT
* Delete → DELETE
# User story
As a developer,
I want to create, view, update, and delete my projects in a single-page web application,
So that I can demonstrate a full-stack data round trip from front-end to database and back, and showcase my work to potential employers.
